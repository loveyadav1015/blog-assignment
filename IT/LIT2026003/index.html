Introduction

Technology has become an important part of our daily lives. From mobile applications to websites, software helps people communicate, learn, and solve problems. I have always been curious about how these technologies work. This curiosity encouraged me to begin my journey into the world of coding.

As an Information Technology student at IIIT Lucknow, I want to develop a strong foundation in programming and understand how computer applications are created. I know that learning to code takes time, patience, and regular practice, but I am ready to improve step by step.

How My Coding Journey Started

My coding journey began when I started exploring programming and learning about computer science. At first, many concepts seemed unfamiliar. Understanding syntax, writing instructions, and finding mistakes in a program required concentration. Gradually, I realised that programming becomes easier when a large problem is divided into smaller steps.

I am currently interested in learning C programming, HTML, CSS, and JavaScript. C programming helps me understand basic concepts such as variables, conditions, loops, and functions. HTML allows me to structure web pages, while CSS and JavaScript help make websites more attractive and interactive.

I also want to explore GitHub , where developers share code and collaborate on projects. Learning Git and GitHub will help me understand version control and contribute to open-source software.

Why I Want to Learn Coding

Coding is not only about writing lines of code. It is also about logical thinking, creativity, and solving problems. I want to learn programming because it can help me build useful applications, work on interesting projects, and understand modern technology.

Some skills I want to develop are:

  • Logical thinking and problem-solving
  • Writing clean and understandable code
  • Developing websites using HTML, CSS, and JavaScript
  • Practising data structures and algorithms
  • Collaborating with other developers
  • Contributing to open-source projects

My Learning Goals

I believe that consistency is more important than trying to learn everything in one day. My plan is to strengthen my basics first and then gradually move towards more advanced topics.

  1. Understand programming fundamentals.
  2. Practise small programming problems regularly.
  3. Learn HTML page structure and semantic elements.
  4. Study CSS and JavaScript for web development.
  5. Learn Git and GitHub for version control.
  6. Build small projects and improve them with practice.

For web development reference material, I can use MDN Web Docs . It provides learning resources for HTML, CSS, and JavaScript.

Challenges and Lessons

One challenge for a beginner is understanding errors in code. Sometimes a missing bracket, incorrect spelling, or small logical mistake can prevent a program from working. Instead of giving up, I want to learn how to read error messages, test my code, and correct mistakes patiently.

I have also learned that asking questions, reading documentation, and practising regularly are useful ways to improve. Every small project can teach me something new.

Conclusion

My journey into coding is just beginning, and there is still a lot for me to learn. I want to stay curious, practise consistently, and use my knowledge to create useful projects. I hope that the skills I develop during my time at IIIT Lucknow will help me become a confident programmer and a responsible contributor to the technology community.

This is only the first step, and I look forward to learning more with every project I complete.
