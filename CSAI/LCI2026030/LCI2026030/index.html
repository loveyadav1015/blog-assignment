BEFORE WE READ HTML Basics let me tell u something about html:
HTML is the basic language used to build all websites.
Think of it as the skeleton or framework of a web page. It uses simple labels called tags, which are written inside angle brackets<> like h1,p. These tags tell the computer what the text actually is, such as a heading, a paragraph, a list, or a link. Every modern web page starts with a special line, !DOCTYPE html with angle brackets on both side, to let the web browser know it is reading modern HTML. By learning just a few basic tags, anyone can easily create and structure their very own simple web page.
