Introduction

When I started college, I had never written a proper program before. Everyone around me kept saying that C++ is a good first language, especially if you want to do problem solving and coding contests later.

In this blog I want to write about how I started, what I learned, what confused me, and how I practiced. I am not an expert at all, so this is just my experience as a beginner.

Getting Started

Setting up the tools

I installed VS Code and a C++ compiler on my laptop with the help of seniors. It took me almost a full evening because the compiler path was not set properly the first time. After that, everything worked fine and I could compile programs from the terminal.

Running my first program

These are the steps I followed to run my first program:

  1. Open VS Code and create a new file called first.cpp.
  2. Write a small program that prints "Hello, World!".
  3. Save the file and open the terminal.
  4. Compile it using the g++ command.
  5. Run the output file and check the result.

Seeing the output on the screen for the first time felt really nice, even though it was only one line.

What I Learned

In the first month I mostly focused on the basics. I firstlt solved upto 500 level problems on CodeChef. The table below shows the topics I covered and how comfortable I feel with each one.

Topic Week How I feel about it
Input and output (cin, cout) 1 Easy
If-else and loops 2 Okay
Arrays 3 A bit tricky
Functions 4 Still learning

Things that confused me

A few things took me some time to understand:

  • Forgetting the semicolon at the end of a line and getting many errors.
  • Array indexing starting from 0 instead of 1.
  • Understanding the difference between int and long long.
  • Reading error messages from the compiler.

Practice

Reading alone does not help much, so I started solving small problems on CodeChef. The beginner problems are simple, like printing squares of numbers or finding the maximum of three numbers. At first I got many wrong answers, but slowly I started getting them right.

If you want to ask me something about my experience, you can send me an email.

Conclusion

After one month, I can say that C++ is not as scary as it looked in the beginning. The most important thing I learned is that practice matters more than just watching videos. Making mistakes and fixing them teaches you a lot.

My plan for the next month is to learn more about functions, strings and the sort function, and to solve at least one problem every day. I will try to completely shift on codeforces before the holidays end. I will also try to learn about the STL (Standard Template Library) and how to use it effectively.
