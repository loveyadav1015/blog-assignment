The First Experience : CODING

Introduction     Journey     Challenges     Conclusion    

Introduction

When I first started coding I had no idea what a loop or an array was. Everything looked like a foreign language. As instructed by seniors, I chose competitive programming and created profile on Codechef first

Competitive programming taught me that coding is not about memorizing syntax. It is about thinking logically, breaking a big problem into small steps, and not giving up after the first wrong answer. Every contest showed me how much I still had to learn, and that kept me motivated to continue.

The Journey

The journey is all this:

  1. Learned the basics with College Wallah YT Channel.
  2. Solved the easy problem on CodeChef.
  3. Practiced several beginner-level problems.
  4. Finished first contest with rating going downwards only.

Challenges

The Challenges are:

  • Getting stuck on a problem for hours with no idea.
  • Time Limit Exceeded errors because of lack of knowledge.
  • Silly mistakes always as usual.
  • Not knowing enough topics like greedy, binary search and basic number theory

Right now, I am unable to move to Codeforces. It's problems are harder and need stronger logic and more required knowledge than I have currently. I treat this as a goal to move forward. I plan to learn more algorithms, practice medium-level problems and try Codeforces problems also.

Conclusion

My first experience with coding has been a mix of frustration and joy. Starting with CodeChef and going on and learning from my mistakes. I have not moved to Codeforces yet, but I know exactly what I need to improve. I am still a beginner and that is okay because every problem I solve makes the next one easier.
