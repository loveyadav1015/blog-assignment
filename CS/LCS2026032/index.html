Git

What is Git?

Git is a tool made by Linus Torvalds, a famous software engineer who also created Linux

It is a very common tool used by many developers all around the world as a VCS and it is most commonly used in combination with the website github

In FOSS wing our seniors(2nd Years) will teach us how to use git in real life projects and how to make the most out of this wonderful tool. We can use git in our projects such as WDA website assignments as well our own personal projects

Examples of other commonly used Version Control Systems:

  1. SVN
  2. Perforce
  3. Mercurial

Github

What is Github?

Github is a platform maintained by microsoft which allows users to save and share their projects online

It helps developers to publish their open source projects and contribute to the community and gain experience

We can use github to show our progress in a project and create a log of all the changes made in a project over a cloud database.

In github we can easily choose who is able to see or edit out projects. It also gives us various other functionalities such as forking, cloning, etc. which help us to improve upon a software without changing the actual file before testing the changes.
